# dreamWorld design notes

Everything visual we've explored for the game lives here: drafts, picks, and reference renders.
Unity ignores this folder (it's outside `Assets/`). New drafts get added here as we go.

## Art direction

- **Look:** PS1 / PSX low-poly 3D. Low-res render (240-320p), dithered 15-bit color, wobbly
  vertex snapping, sharp pixel textures, per-vertex lighting, fog.
- **Characters:** cozy cartoon people, slim hourglass body, natural rounded head,
  stylized cartoon eyes (not anime). Faces are pixel-art decals (128px per layer).
- **Style range:** grunge and baggy (flannel, cargo, combat boots, fishnets, chokers) next to
  girly (puff sleeves, gingham ruffles, ribbons, star clips) and Y2K (low-rise, crop tops).
- **World:** night-time mushroom village in the dream woods: glowing purple/blue/pink
  mushrooms, mushroom houses, thatched cottages with warm windows, lamp-lit cobble paths.
- **UI:** cozy pixel terminal (VT323 + Pixelify Sans), framed panels, CRT scanlines,
  `> typed_text_` banners.

| File | What it is |
|---|---|
| `Faces/face_drafts_round1.png` | Round 1, bigger cartoon eyes: A big round, B glossy dot, C doe, D sparkly, **E soft almond**, F wide toon |
| `Faces/face_drafts_round2_angular.png` | Round 2, angular / almond family: G cat eye, H hooded, I sharp diamond, J upturned, K puppy, L pixel hex, M monolid, N starry almond, O slit cat |
| `Faces/old_small_cartoon_eyes.png` | The earlier small cartoon eyes (too small, felt scary) |
| `Faces/old_anime_eyes.png` | The earlier anime eyes (felt uncanny) |

**Current pick:** E soft almond is the default face. The eye menu also has A, B, C, D, F
(round, glossy, doe, sparkly, toon) and round-2 picks J, N, G, M, L, K
(upturned, starry, cat eye, monolid, pixel hex, puppy).

`Faces/eye_sliders_default_big_smallwide_closehigh.png` shows the eye sliders: size, spacing,
height (brows move with the eyes; mouth and blush stay put), plus a reset.

All face designs are numbers in `ArtSource/eye_designs.py` (shape curve, tilt, hood, iris size,
pupil type, lid/wing/lashes, mouth, brows, blush), so mixing ("H's eyes with N's mouth") is easy.

## Decisions log

- Unity 6.3 (not Godot/Unreal): we know it, the PS1 pipeline is built, and it can do online play.
- Characters and world props are generated by scripts (`ArtSource/build_dreamer.py`,
  `ArtSource/build_world.py`) so everything can be re-tuned and rebuilt in one go.
- Third-party art is CC0 only (Screaming Brain Studios, Poly Haven, ambientCG, iPoly3D glasses);
  sources are listed in `ArtSource/ThirdParty/*/SOURCE.txt` / `LICENSE.txt`.
- Multiplayer: FishNet (free for games). Small online test first (a few friends); the look syncs as
  the tiny CharacterSave JSON. Tested: host + client, and a headless server with two clients.
